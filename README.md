# Amazon-Sales-Analysis-Streamlit
Interactive sales analytics dashboard built using Python, Streamlit, Pandas, and Plotly for Amazon sales data analysis.

## Project Overview
This project is an interactive sales analytics dashboard developed using Python and Streamlit to analyze Amazon End of Season Sale data. The dashboard provides insights into sales performance, order trends, category-wise analysis, and state-wise sales distribution.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## Dashboard Features
- Interactive Filters
  - State Filter
  - Category Filter

- Key Performance Indicators (KPIs)
  - Total Sales
  - Total Orders
  - Delivered Orders
  - Returned Orders

- Sales Analysis
  - Category-wise Analysis
  - State-wise Analysis
  - Order Performance Analysis
  - Sales Trend Tracking

## Business Insights
- Identifies high-performing product categories
- Tracks sales across different states
- Monitors delivered and returned orders
- Helps understand customer purchasing patterns
